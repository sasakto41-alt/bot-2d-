# ⛏ Deep Digger — плагин для Paper 1.20.4+

**Deep Digger** — это постоянная система личных шахт для Minecraft серверов Paper 1.20.4+.
Каждый игрок получает собственную шахту шириной в 1 блок, копает вниз, добывает руду, зарабатывает внутриигровую валюту, покупает лучшие кирки, улучшает глубину своей шахты, нанимает работников и получает пассивный доход от их добычи.

## Установка

1. Скопируйте файл `DeepDigger-1.0.0.jar` в папку `plugins/` вашего сервера Paper 1.20.4+.
2. Запустите сервер один раз — плагин создаст конфигурацию в `plugins/DeepDigger/`:
   - `config.yml` — основные настройки
   - `messages.yml` — все текстовые сообщения
   - `data/players.yml` — данные игроков
   - `data/mines.yml` — данные шахт
3. Перезапустите сервер или выполните `/deepdigger admin reload`.
4. Зайдите в мир `world` и выполните команду `/deepdigger` — будет создана ваша личная шахта.

**Важно:** используйте существующий мир с названием `world` (или измените `world.name` в `config.yml`).

## Сборка из исходников

Для сборки нужен JDK 17 и Gradle 8.x.

```bash
cd deepdigger
gradle build
```

Готовый JAR появится в `build/libs/DeepDigger-1.0.0.jar`.

## Команды

Основная команда: `/deepdigger` (алиасы: `/dd`, `/dig`, `/mine`).

### Игроки

| Команда                          | Описание                                     |
|----------------------------------|----------------------------------------------|
| `/deepdigger`                    | Открыть главное GUI-меню                     |
| `/deepdigger help`               | Показать список всех команд                  |
| `/deepdigger menu`               | Открыть главное меню                         |
| `/deepdigger money`              | Показать баланс                              |
| `/deepdigger mine`                | Открыть меню шахты                           |
| `/deepdigger upgrade`            | Открыть меню улучшения шахты                 |
| `/deepdigger teleport`           | Телепорт к своей шахте                       |
| `/deepdigger invite <ник>`       | Пригласить игрока в качестве работника       |
| `/deepdigger accept`             | Принять приглашение                          |
| `/deepdigger deny`               | Отклонить приглашение                        |
| `/deepdigger kick <ник>`         | Исключить работника                          |
| `/deepdigger members`            | Список работников вашей шахты               |

### Администраторы

| Команда                                  | Описание                          |
|------------------------------------------|-----------------------------------|
| `/deepdigger admin create <ник>`         | Создать шахту для игрока          |
| `/deepdigger admin reset <ник>`          | Сбросить шахту игрока             |
| `/deepdigger admin delete <ник>`         | Полностью удалить шахту           |
| `/deepdigger admin tp <ник>`             | Телепортироваться к шахте игрока  |
| `/deepdigger admin reload`               | Перезагрузить конфигурацию        |

## Конфигурация config.yml

```yaml
mine:
  start-depth: 30        # Стартовая глубина
  max-workers: 5          # Макс. работников на шахту
  upgrades:               # Таблица апгрейдов
    2: { depth: 50,  price: 1000 }
    3: { depth: 75,  price: 2500 }
    4: { depth: 100, price: 5000 }
    5: { depth: 150, price: 10000 }
    6: { depth: 200, price: 25000 }
    7: { depth: 300, price: 50000 }

economy:
  worker-percent: 70     # Процент работнику
  owner-percent: 30       # Процент владельцу

ores:
  coal:    { min-depth: 10,  max-depth: 50,  chance: 0.10,  reward: 2 }
  iron:    { min-depth: 30,  max-depth: 100, chance: 0.07,  reward: 5 }
  gold:    { min-depth: 60,  max-depth: 150, chance: 0.04,  reward: 10 }
  diamond: { min-depth: 100, max-depth: 300, chance: 0.015, reward: 50 }

lighting:
  torch-radius: 5        # Радиус света факела
  darkness-enabled: true # Темнота без факела

regeneration:
  delay-seconds: 3       # Через сколько секунд блок восстанавливается
```

Все строки сообщений вынесены в отдельный файл `messages.yml` с поддержкой цветовых кодов (`&a`, `&c`, `&l` и т. д.).

## Система шахт

- **Ширина шахты 3×3 блока** (настраивается в `mine.shaft-width`, только нечётные числа).
- Только вертикальное развитие **вниз**.
- Стартовая глубина — 30 блоков.
- Координаты выдаются автоматически `MineManager`-ом, шахты разных игроков не пересекаются (по умолчанию шаг = 100 блоков по X).
- **Шахта парит в воздухе** на высоте Y=120 (настраивается в `world.surface-y`).
- **Боковые стены из стекла** — видно мир, как в 2D-игре, но выйти вбок нельзя.
- **Несокрушимый пол из бедрока** внизу шахты — нельзя сломать, копать ниже нельзя.
- Платформа со сплошным забором (2 блока в высоту) вокруг входа — игрок не падает с шахты.
- **Игрок не может покинуть пределы шахты** — выход за границы безопасной зоны блокируется автоматически.
- **Парящие голограммы над платформой** — 5 кликабельных текстов-кнопок на заборе:
  - ⛏ МЕНЮ — открыть главное GUI
  - ⬆ УЛУЧШИТЬ — меню улучшения шахты
  - ⛏ КИРКИ — магазин кирок
  - ↻ ОБНОВИТЬ ШАХТУ — мгновенно регенерировать все блоки в шахте (единственный способ вернуть блоки — авто-реген отключён)
  - ⬆ **ТП НА ВЕРХ** — внизу шахты, телепортирует на поверхность
- **Безопасная зона** — несокрушимый блок бедрока в самом центре платформы. На нём появляется игрок после телепорта.
- **Добыча не даёт лута** — блок ломается, деньги сразу на баланс, никаких предметов в инвентаре.
- **Авто-регенерация отключена** — блоки не восстанавливаются сами. Только клик по голограмме «↻ ОБНОВИТЬ ШАХТУ» вернёт все блоки.

## Система работников

- Владелец шахты приглашает игроков через `/deepdigger invite <ник>`.
- Приглашённый игрок принимает или отклоняет через GUI либо `/deepdigger accept|deny`.
- Работник получает доступ к шахте и может копать, но **не может**:
  - улучшать шахту;
  - приглашать других;
  - исключать работников;
  - менять настройки.
- Максимальное количество работников — 5 (настраивается в `mine.max-workers`).

## Экономика

- Собственная валюта (без Vault). Баланс хранится в `data/players.yml`.
- При добыче работником доход делится: 70% работнику, 30% владельцу (настраивается в `economy`).
- Если владелец копает сам — он получает 100%.
- Деньги сохраняются между перезаходами и перезапусками сервера.

## Улучшение шахты

Через GUI `/deepdigger upgrade` или кнопку в главном меню.

| Уровень | Глубина | Цена     |
|---------|---------|----------|
| 1       | 30      | (старт) |
| 2       | 50      | $1 000  |
| 3       | 75      | $2 500  |
| 4       | 100     | $5 000  |
| 5       | 150     | $10 000 |
| 6       | 200     | $25 000 |
| 7       | 300     | $50 000 |

При покупке новой уровень шахта автоматически увеличивается — новые нижние уровни генерируются.

## Кирки

| Кирка   | Цена    | Прочность |
|---------|---------|-----------|
| Wood    | 0       | 25 (очень слабая) |
| Stone   | $500    | 250       |
| Iron    | $1 500  | 500       |
| Diamond | $5 000  | 1 000     |

- **Деревянная кирка очень слабая** — ломается через ~25 блоков. При поломке игрок **автоматически получает новую деревянную кирку** бесплатно, чтобы не застрять. Мотивирует купить лучшую.
- Чтобы открыть магазин кирок, **возьмите кирку Deep Digger в руку и нажмите Shift**.
- Кирки покупаются последовательно (нельзя пропустить уровень).
- Разные руды требуют разный уровень кирки:
  - Stone/Coal — Wood
  - Iron — Stone
  - Gold — Iron
  - Diamond — Diamond

## Руда

Руда генерируется в зависимости от **глубины** (от поверхности шахты):

| Руда    | Глубина      | Шанс  | Награда |
|---------|--------------|-------|---------|
| Уголь   | 10–50        | 10%   | $2      |
| Железо  | 30–100       | 7%    | $5      |
| Золото  | 60–150       | 4%    | $10     |
| Алмаз   | 100–300      | 1.5%  | $50     |

При добыче:
- проигрывается звук (отдельный для редкой руды);
- частицы для редкой руды;
- HUD обновляется автоматически;
- деньги начисляются мгновенно;
- блок восстанавливается через 3 секунды — **дюп невозможен**.
